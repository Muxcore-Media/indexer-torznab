# Compatibility

## Core Version

| Module Version | Core Version | Status |
|----------------|-------------|--------|
| v0.1.0         | v0.4.0+     | Current |

## Contracts

Implements `Indexer` from `github.com/Muxcore-Media/contracts-indexer` (`IndexerService` gRPC).

## Upstream

Compatible with Torznab/Newznab search endpoints exposed by Prowlarr (`/N/api`), Jackett (`/api/v2.0/indexers/.../results/torznab`), and similar aggregators.
