# Compatibility

## Core Version

| Module Version | Core Version | Status |
|----------------|-------------|--------|
| v0.1.5         | v0.5.8+     | Current |
| v0.1.4         | v0.5.8+     | Supported |

## Contracts

Implements `Indexer` from `github.com/Muxcore-Media/contracts-indexer` (`IndexerService` gRPC, contract version v1).

## Upstream

Compatible with Torznab/Newznab search endpoints exposed by Prowlarr (`/N/api`), Jackett (`/api/v2.0/indexers/.../results/torznab`), and similar aggregators.
